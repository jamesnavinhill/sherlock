# Active Plans

`docs/plans/` is for current working plans that describe active execution order for the present codebase.

Use this directory for:

- current cleanup plans
- active implementation roadmaps
- ordered follow-on execution streams that are still relevant to the current repo

Do not use this directory for:

- superseded plans kept only for historical context
- exploratory notes that no longer reflect current code or current priorities

Historical plans live under `docs/_legacy/plans/`.

Current active entries should stay aligned with:

- `README.md`
- `docs/operations/ARCHITECTURE.md`
- the actual code under `src/`
