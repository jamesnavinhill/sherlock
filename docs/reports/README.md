# Active Reports

`docs/reports/` is for current findings, audits, closeouts, and handoff reports that still describe the active codebase or the active workstream.

Use this directory for:

- current architecture or cleanup audits
- closeout reports for active implementation streams
- current findings records that are still relevant to ongoing work

Do not use this directory for:

- historical reports preserved only for reference
- reports whose code assumptions no longer match the active repo

Historical reports live under `docs/_legacy/reports/`.

When a report stops being part of the active working context, move it to `_legacy` rather than leaving active docs ambiguous.
