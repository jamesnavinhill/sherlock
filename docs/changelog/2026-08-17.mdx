## Updates

### Vercel Web Analytics on hosted deployments

Sherlock deployments on [Vercel](/deployment/vercel) now include Vercel Web Analytics. Aggregate, privacy-friendly traffic data (page views and visitor counts) is reported for the hosted app, with no changes to how investigation data is stored or shared. Analytics only run when the app is deployed to Vercel and Web Analytics is enabled in the project dashboard, so self-hosted and local instances are unaffected.
